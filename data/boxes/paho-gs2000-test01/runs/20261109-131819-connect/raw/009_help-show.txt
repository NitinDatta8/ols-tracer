show                               Description: The "show" command is used to retrieve information from the system. Show command support
                                   retrieve the state and running configuration attributes for input statement or identifier.
                                   
                                   Command syntax: show [statement-path] [identifier] [attribute] [option]
                                   
                                   Wildcard: The show command support wildcard "*" replace full or part of followed index: slot-id,
                                   port-name, interface-name. The "*" will replace all the characters of current index after the pre
                                   one.
                                   e.g., 
                                   port 1-1-c* 
                                   och 1-*-l* 
                                   eth 1-1-* 
                                   
                                   Command environment: show mode, configuration mode 
                                   
                                   Output format: 
                                   Output data by table format when show multiple same type identifiers info. The units of attribute
                                   shall be mark at the title. Config and state attributes are displayed in two table. If one table include
                                   too many attributes to cause out of window width, it shall decouple to multi table, each one has the
                                   identifier column. If one table hasn�t any data, it shall still output the title of the table.
                                   Output data by list format when show one identifier or statement. The units of attribute shall be
                                   mark after the value.
                                   Show multiple same type identifiers info by table, show one identifier by list
                                   To show not existed identifier shall report failure, error message "target not found"
                                   Output statistics data with standalone table format <instant> | <avg> | <min> | <max> <units>
                                   
                                   Option:
                                   -c show configure value
                                   -s show state value
                                   -t show statistics only
                                   w/o option show both configure and state value
