
Commands available:
quit                               Disconnect
logout                             Disconnect
exit                               Exit from current mode
enable                             Turn on privileged commands
disable                            Turn off privileged commands
configure                          Enter configuration mode
show                               The "show" command is used to retrieve information from the system
help                               Show available commands
ping                               Ping remote target and feedback the result
traceroute                         Trace the route of remote target and feedback the result
date-time                          Set system datetime and time zone or show current system datetime.
cls                                renew and clear current CLI window display
history                            Output history inputted commands of current session.
change-password                    Change current login user’s password
